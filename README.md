# Java 11 to 17 sample

`java-11/` is a small program that compiles on JDK 11. It calls `java.security.acl.Acl`, which JDK 17 removed.

`java-17/` is written by [UpgradeProof](https://github.com/AnuragSingla911/UpgradeProof) after the public tests pass on JDK 17. The original `java-11/` tree stays as it is.
